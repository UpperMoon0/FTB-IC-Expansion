# Industrial Contraptions Expansion: Core

**Industrial Contraptions Expansion: Core** is the shared foundation for the IC Expansion addon suite for [FTB Industrial Contraptions](https://www.curseforge.com/minecraft/mc-mods/ftb-industrial-contraptions-forge) by the FTB Team.

Core provides the common registration and machine compatibility infrastructure used by IC Expansion modules such as [Industrial Contraptions Expansion: Generators](https://www.curseforge.com/minecraft/mc-mods/ic-expansion-generators).

## Supported versions

- **Minecraft 1.19.2** — Forge
- **Minecraft 26.1.2** — NeoForge

Install the file that matches your exact Minecraft version and loader.

## Required dependency

- **FTB Industrial Contraptions**

Core itself does **not** require Patchouli. Guide, recipe-viewer, and tooltip integrations belong to the content modules that use them.

## What Core does

- Provides shared infrastructure for IC Expansion modules.
- Keeps version-specific FTBIC compatibility behind a common expansion boundary.
- Preserves FTBIC Zap energy behavior and FE interoperability for expansion machines.
- Allows the expansion suite to support the legacy Forge line and the current NeoForge line from one maintained repository.

If you only install a content module such as IC Expansion: Generators, install Core alongside it when CurseForge does not resolve the dependency automatically.

## Modpack use

You may freely include IC Expansion mods in modpacks.
