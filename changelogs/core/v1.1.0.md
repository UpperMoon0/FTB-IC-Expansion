# IC Expansion: Core 1.1.0

## Compatibility
- Accept NsTut Lib 0.8.1 and newer on NeoForge 26.1.2 without an arbitrary 0.9 upper version ceiling.
- Preserve the library's existing required/BOTH dependency semantics and minimum version.
- Verify the expanded `META-INF/neoforge.mods.toml` in the packaged Core jar contains exactly one required `nstutlib` entry with `versionRange="[0.8.1,)"`.

## Release notes
- Increment Core's minor version for its changed dependency metadata.
- CI covers Forge 1.19.2, NeoForge 26.1.2, shared tests and packaged metadata. Future NsTut Lib API versions still require real runtime verification.
