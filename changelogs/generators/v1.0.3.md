# IC Expansion: Generators 1.0.3

### Generator behavior

- Restore and modernize the Advanced Generator and Advanced Geothermal Generator for NeoForge 26.1.2 while preserving the Forge 1.19.2 behavior line.
- Advanced Generator defaults to **30 Zap/t** and now consumes the same datapack-driven Basic Generator fuels supported by FTB Industrial Contraptions instead of relying on a hardcoded fuel assumption.
- Scale Advanced Generator fuel duration from FTBIC's configured Basic Generator output, preserving the intended energy-per-fuel relationship when packs rebalance upstream values.
- Advanced Geothermal Generator defaults to **60 Zap/t** and scales lava consumption from FTBIC's configured Geothermal Generator output.
- Restore compatible battery charging behavior on the modern generators.
- Expose fuel, battery, and geothermal fluid storage to the appropriate automation APIs.

### Compatibility

- Keep generator output aligned with FTBIC Zap cable transport and FE conversion behavior.
- Add JEI integration for the appropriate FTBIC generator fuel categories.
- Add Jade information for stored energy, fuel state, and lava storage.
- Keep the 1.19.2 Patchouli extension for the FTBIC guide and add GuideME pages for the 26.1.2 FTBIC guide.
- Load JEI, Jade, GuideME, and Patchouli in the relevant development environments for compatibility testing.

### Fixes

- Correct 1.19.2 generator loot-table namespaces so the expansion blocks drop correctly in survival.
- Remove hardcoded assumptions about upstream Basic Generator and Geothermal Generator output values.
- Preserve crafting remainders when the Advanced Generator consumes fuel.

### Documentation and release

- Rewrite the player-facing README and CurseForge description to remove the obsolete "no longer maintained" notice.
- Document that Advanced Generator accepts all fuels recognized by FTBIC's Basic Generator recipe type, including datapack-added fuels.
- Expand Patchouli and GuideME pages with throughput, efficiency, battery, automation, JEI, Jade, and recipe information.
- Use this versioned changelog as the CurseForge file changelog and GitHub release notes.
